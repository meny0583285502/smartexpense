# SmartExpense - מערכת ניהול קבלות למוסד

## מבנה הפרויקט
```
worker/       Cloudflare Worker + D1 database (ה-backend)
admin/        דף דשבורד פשוט (יעבור בהמשך ל-GitHub Pages, כמו X-NET)
```

## התקנה ראשונית (פעם אחת)
```bash
cd worker
npm install
npx wrangler login
npx wrangler d1 create smartexpense-db
# תעתיק את ה-database_id שמתקבל לתוך wrangler.toml
npm run db:init:remote
npx wrangler deploy
```

## הנחות עבודה שנקבעו (לתקן אם משהו לא נכון)
- מבנה בדרייב: `2026/<חודש>/לא אומתו`, `2026/<חודש>/הונפקו`, `2026/<חודש>/לא הונפקו`.
- "לא אומתו" = קבלות שעברו OCR אבל עדיין לא אושרו ידנית ע"י המשתמש (מייל/מצלמה/גלריה/העלאה ידנית - כולן נכנסות לכאן קודם).
- רק אחרי לחיצת אישור, הקבלה "זזה" בפועל לתיקיית "הונפקו".
- לחיצה על "שלח קבלות" סוגרת מחזור חודשי ומעדכנת סטטוס הגשה על ההוצאות.
- בסיום החודש, אחרי ששלחת את רשימת "לא הונפקו" לרואה החשבון, ניתן למחוק את התיקייה המתאימה.
